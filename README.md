## Proyek Unggulan

|<div style="width:140px; font-weight: 600; color: #E8B84B; font-size: 13px;">Proyek</div>|<div style="width:380px; color: #6C727F; font-size: 12px;">Yang Diselesaikan</div>|
|---|---|
|**Absensi-liqo** · Vue, Supabase, QR|Absensi digital berbasis QR Code untuk kegiatan liqa/halaqah — menggantikan presensi manual dengan scan kartu personal per anggota, lengkap dengan monitoring real-time dan export laporan.|
|**halaqah** · Python, Flask|Manajemen halaqah/kelompok belajar Islami: pencatatan sesi, absensi anggota, dan dashboard murabbi dalam satu platform.|
|**KASAPRO** · JavaScript, Node.js|Aplikasi keuangan mobile-first untuk UMKM — mencatat pemasukan, pengeluaran, dan mengelola anggota secara cepat dari smartphone.|
|**LSTM-Demand-Forecasting** · Python, TensorFlow|Model deep learning LSTM untuk prediksi permintaan produk dari data time-series — eksperimen pemanfaatan neural network untuk forecasting.|
|**pangan-usd-idr-dashboard** · TypeScript, Next.js|Dashboard real-time monitoring harga pangan Indonesia dan nilai tukar USD/IDR — data dari sumber resmi dalam satu tampilan.|
|**simormawa** · PHP, Laravel, Filament|Sistem informasi organisasi mahasiswa (ORMAWA) Universitas Adzkia — workflow pengajuan proposal, review dokumen, dan manajemen struktur organisasi.|
